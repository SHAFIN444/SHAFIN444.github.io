# Shafin Shahriar — Portfolio

Static portfolio with English and Korean pages.

To publish at https://shafin444.github.io/:
1. Create a public repository named SHAFIN444.github.io under the SHAFIN444 account.
2. Upload all files in this folder to the repository root.
3. In Settings > Pages, select Deploy from a branch, main, / (root), then Save.

The homepage is index.html. The Korean page is ko.html. No build step is needed.
